# Website direction

A small, personal corner of the web: a 1990s-inspired homepage, readable project
notes, and the existing Hugo blog.

- Curate the homepage instead of adding live dashboards or repository feeds.
- Keep project notes useful, concise, bilingual, and linked to their source.
- Publish long-form writing through Hugo.
- Keep ordinary browsing free of JavaScript and external font dependencies.
- Preserve mobile access, keyboard navigation, and stable project URLs.

See [DEVELOPMENT.md](DEVELOPMENT.md) for the current implementation.
